# data/ — raw dataset templates

These CSV files define the exact column headers the system expects for each kind
of record. They are the blank templates a data-collection effort would fill in
with real hospital/clinic figures:

- `locations-raw.csv`          — departments / wards / service points
- `routes-raw.csv`             — corridors / roads between locations
- `service-requests-raw.csv`   — patient/service requests with an urgency level
- `resources-raw.csv`          — staff / equipment / ambulances / beds
- `index-number-parameters.md` — how project parameters are derived from index numbers

The application does not read this folder directly. It runs on the ready-to-use
dataset in `database/seed-data/`, which is generated by `database.SeedDataGenerator`
using these same column headers. To drive the system from real figures instead,
fill these templates in and copy them into `database/seed-data/` with the matching
file names.

## About this dataset

These files model University Hospital, Legon (University of Ghana Health Services
Directorate) for the DCIT 308/204 Ghana Smart Service Operations Optimizer project.
Department/unit names are grounded in the hospital's published structure
(ug.edu.gh/healthservices/hospital-units, /services); coordinates are small offsets
around the real University of Ghana, Legon campus (~5.6505N -0.1855W). Sub-wards,
room-level service points, corridor distances/times/road-condition weights, request
logs, and resource figures are plausible illustrative figures for the class project,
NOT verified real hospital records (no real patient or staff data is used).
