# specs/ — the bridge between "what we need" and the Java code

data-structures/  Owner: Data Structures Spec Team (Role 5) — one .md per structure
algorithms/       Owner: Algorithms Spec & Analysis Team (Role 6) — one .md per family

These are NOT code. They are precise, complete descriptions (operations,
diagrams, trace tables, example inputs/outputs) that Team Leader turns into Java
using Claude Code. The more precise the spec, the faster and more correct
the resulting code.
